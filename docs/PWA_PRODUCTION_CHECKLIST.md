### 1. بنود التحقق الفنية والأمنية:

1. **ملف البيان (Web App Manifest):**
   - المسار: `/manifest.json`
   - اسم التطبيق: `مدرسة الكاروز للكتاب المقدس`
   - الاسم القصير: `الكاروز`
   - نمط العرض: `standalone`
   - ألوان الهوية: لون القرمزي الكنسي `#881337` وخلفية داكنة `#0f172a`.
   - اتجاه الواجهة واللغة: `dir: "rtl"`, `lang: "ar"`.
   - الأيقونات: أيقونات متوافقة بدقة `192x192` و `512x512` مع دعم `maskable`.

2. **عامل الخدمة (Service Worker):**
   - المسار: `/sw.js`
   - استراتيجية التخزين المؤقت: Cache First للأصول الثابتة و Network First للبيانات الحساسة.
   - **أمان الجلسات وعزل الحسابات:** حظر تخزين أي بيانات شخصية أو توكنات في الـ Cache لضمان عدم تسريب بيانات عند تبديل الحسابات.
   - معالج إشعارات الويب: `push` و `notificationclick` لفتح التطبيق والانتقال للرابط المستهدف.

3. **تجربة التثبيت على المنصات:**
   - **Android:** إمكانية التثبيت الفوري كـ Native Web App مع استلام Push Notifications.
   - **iOS / Safari:** دعم `appleWebApp.capable` والأيقونات المتجاوبة.
   - **Desktop (Chrome/Edge):** زر تثبيت التطبيق على سطح المكتب.

4. **الأمان والتشفير:**
   - اتصال مشفر حصري بـ HTTPS.
   - حظر كشف `VAPID_PRIVATE_KEY` في ملفات الواجهة.
