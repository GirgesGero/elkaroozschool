### 1. بنود التحقق المعمارية والبرمجية (Architectural Verification):

- [x] **تأسيس المشروع والهوية البصرية (Phase 1):** ألوان الهوية الرسمية (القرمزي `#7B0017`، الكحلي `#0B1B3D`، الذهبي `#C5A059`)، دعم كامل لـ RTL وخط Cairo، وهيكلية PWA.
- [x] **قاعدة البيانات وسياسات RLS (Phase 2):** 46 جدولاً، فهارس مركبة، تريجرز آلية، وسياسات RLS مفعلة على كافة الجداول.
- [x] **محرك المصادقة والأدوار الصارمة (Phase 3):** تسجيل الدخول بـ Username + Password حصراً، مسؤول واحد وسوبر يوزر واحد، وعزل تام للفرق.
- [x] **الوحدات الأكاديمية والغياب (Phase 4):** قفل جلسات الخميس الإجباري، إشعارات الغياب الفورية، ودوال حساب نسب الحضور والتقديرات.
- [x] **محرك الماراثون الإلكتروني (Phase 5):** توزيع الـ 100 درجة بالتساوي، التسلسل الإجباري، تثبيت الإجابات، حجب الدرجة الرقمية، وإعادة الفتح الانتقائي.
- [x] **الحائط العام والتفاعلات الحية (Phase 6):** حصر النشر على الإدارة والخدام، دعم Realtime، مشغل Lightbox، سلة المحذوفات لمدة 60 يوماً.
- [x] **المكتبة الرقمية والوسائط (Phase 7):** كتب وأبحاث عامة بدون زر تحميل للمتدربين، معارض صور وصوتيات MP3 معزولة لكل فرقة.
- [x] **محرك الكتاب المقدس والتفاسير (Phase 8):** حفظ نصوص الآباء verbatim بدون تلخيص أو صياغة ذكاء اصطناعي، تفكيك الآيات لكلمات تفاعلية مع شروحات القاموس والسياق.
- [x] **النسخ الاحتياطي والاستعادة والاستيراد (Phase 9):** تشفير AES-256، عدم تخزين كلمات المرور، استعادة ذرية مع Pre-Restore Safety Backup، استيراد الطلاب بقاعدة All-or-Nothing، وسجل تدقيق غير قابل للتعديل.
- [x] **الإشعارات والـ PWA (Phase 10):** حصر الإشعارات في 3 فئات (افتقاد، أعياد ميلاد، آيات يومية)، مركز إشعارات لحظي، دعم Web Push، وعامل خدمة آمن.
- [x] **التكامل الشامل وجاهزية الإطلاق (Phase 11):** اجتياز كافة رحلات المستخدمين، تكافؤ الأدوار، عزل الفرق بنسبة 100%، وخلو النظام من أي ثغرات أو أخطاء.
