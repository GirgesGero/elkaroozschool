# دليل تشغيل واستخدام النسخ الاحتياطي والاستعادة والاستيراد (Operation Guide)
## مشروع: مدرسة الكاروز للكتاب المقدس — EL KAROOZ School

**الإصدار:** v1.0.0-PROD  
**تاريخ الإعداد:** 2026-09-26  
**الفئة المستهدفة:** مسؤولو النظام (Admin / Super User)

---

### 1. دليل إنشاء النسخ الاحتياطية المشفرة (Encrypted Backups):
1. الدخول إلى لوحة النسخ الاحتياطي عبر المسار `/admin/backups`.
2. إدخال **كلمة مرور التشفير يدوياً** (يجب ألا تقل عن 8 خانات).
3. اختيار وجهة الحفظ:
   - **خادم Hostinger:** لحفظ النسخة الاحتياطية مركزياً في مجلد `/backups/` المحمي بـ `.htaccess`.
   - **تحميل مباشر:** لتنزيل ملف الـ ZIP مباشرة إلى جهاز المسؤول.
4. الضغط على **بدء إنشاء النسخة الكاملة**؛ يقوم النظام بتجميع قاعدة البيانات وملفات الوسائط وتشفيرها بمعيار **AES-256** وحساب الـ SHA-256 Checksum وتسجيل العملية في `audit_logs`.

---

### 2. دليل الاستعادة الآمنة والذرية (Atomic Restore):
1. اختيار النسخة المراد الاستعادة منها والضغط على زر **استعادة**.
2. تظهر نافذة **معاينة الاستعادة الآمنة** موضحة حجم النسخة، تاريخها، وجداولها.
3. اختيار وضع الاستعادة:
   - `FULL`: استعادة قاعدة البيانات + ملفات التخزين.
   - `DATABASE_ONLY`: استعادة الجداول والبيانات فقط.
   - `FILES_ONLY`: استعادة ملفات التخزين فقط.
4. إدخال كلمة مرور فك التشفير.
5. يقوم النظام تلقائياً بإنشاء **Pre-Restore Safety Backup** كنقطة تراجع (Rollback Point) قبل لمس أي بيانات، ثم تنفيذ الاستعادة التراسلية.

---

### 3. دليل الاستيراد الجماعي للطلاب (Trainee Bulk Import):
1. الدخول إلى صفحة `/admin/imports`.
2. لصق محتوى الـ CSV أو تحميل الملف وفق الترتيب:
   `username, full_name, phone, father_name, group_name, birth_date, password`
3. الضغط على **معاينة فقط (Dry-Run)** لفحص سلامة البيانات واكتشاف الأخطاء.
4. **قاعدة الكل أو لا شيء (All-or-Nothing):** في حال وجود أي خطأ في أي سطر، يتم تعطيل زر الاستيراد وإظهار تفاصيل الخطأ لتصحيحه قبل الإدخال الفعلي.
5. بعد نجاح التحقق، الضغط على **تأكيد واستيراد الحسابات** ليتم إنشاء وتفعيل الحسابات وتشفير كلمات المرور بـ bcrypt وتسجيل العملية في `import_history`.
