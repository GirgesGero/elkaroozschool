# دليل التشغيل والتطوير المحلي الشامل (Local Development & Operations Guide)
## مشروع: مدرسة الكاروز للكتاب المقدس — EL KAROOZ School

**الإصدار:** v1.0.0-PROD (Final Release)  
**نظام التشغيل المدعوم:** Windows 10 / 11 (One-Click Launcher)

---

### 1. المتطلبات الأساسية (Prerequisites):
- **Node.js:** الإصدار 18+ أو 20+ (موصى به: v20.x أو v26.x).
- **Git:** لأدوات سحب وتحديث النظام.
- **PHP (اختياري محلياً):** الإصدار 8.1+ مع امتدادات `zip, openssl, json, mbstring` (الخادم الخلفي يعمل مستضافاً على Hostinger).

---

### 2. أدوات التشغيل بنقرة واحدة (One-Click Windows Launchers):

#### أ. تشغيل المشروع بالكامل (`RUN_ELKAROOZ.bat`):
يقع الملف في المجلد الرئيسي للمشروع، ويقدم قائمة خيارات تفاعلية:
1. **[1] تشغيل المشروع بالكامل:** يطلق واجهة Next.js PWA على المنفذ `3000` وخادم PHP API على المنفذ `8000` في نوافذ منفصلة.
2. **[2] تشغيل الواجهة فقط (Next.js):** إطلاق المنصة على `http://localhost:3000`.
3. **[3] تشغيل الخادم الخلفي فقط (PHP):** إطلاق واجهة الـ API على `http://localhost:8000`.
4. **[4] تشغيل حزمة الاختبارات الشاملة (Full E2E Test Suite):** تشغيل كافة الاختبارات الآلية لجميع المراحل الـ 11.
5. **[5] تشغيل فحص البناء الإنتاجي (`npm run build`):** التحقق من سلامة الأنواع وترجمة كافة المسارات الـ 20.
6. **[6] فحص البيئة والمتطلبات (Environment Check):** فحص توفر Node.js, npm, Git, PHP.
7. **[7] فحص صحة قاعدة البيانات (Database Health Check):** اختبار الاتصال المباشر وقراءة الجداول.
8. **[8] إيقاف تشغيل الخوادم (Stop Servers):** إنهاء عمليات المشروع بأمان.

#### ب. إيقاف خوادم المشروع بأمان (`STOP_ELKAROOZ.bat`):
يقوم بإغلاق العمليات المستمعة على المنفذين `3000` و `8000` فقط دون التأثير على برامج الجهاز الأخرى.

#### ج. تشغيل الاختبارات الآلية (`TEST_ELKAROOZ.bat`):
يقوم بتشغيل اختبارات البناء والأنواع، ورحلات المستخدمين الأربعة، وعزل الفرق، ومحرك الكتاب المقدس، والنسخ والاستيراد والإشعارات، وإظهار تقرير النتائج المجمعة.

---

### 3. المنافذ والمتغيرات البيئية (Ports & Configuration):
- **الواجهة الأمامية (Frontend):** `http://localhost:3000`
- **الخادم الخلفي (Backend API):** `http://localhost:8000` أو رابط Hostinger الإنتاجي.
- **ملف الإعدادات البيئية للواجهة:** `frontend/.env.local`
  ```env
  NEXT_PUBLIC_SUPABASE_URL=https://kgqgnqjkrghvktymbimz.supabase.co
  NEXT_PUBLIC_SUPABASE_ANON_KEY=[REDACTED]
  NEXT_PUBLIC_BACKEND_API_URL=https://api.elkarooz-school.com
  ```

---

### 4. استكشاف الأخطاء الشائعة (Troubleshooting):
- **المنفذ 3000 مشغول:** قم بتشغيل `STOP_ELKAROOZ.bat` لإخلاء المنفذ ثم أعد التشغيل.
- **مشكلة في الحزم:** انتقل إلى مجلد `frontend` ونفذ `npm install`.
- **أخطاء الصلاحيات:** تأكد من تسجيل الدخول بحساب المسؤول `admin_user` أو السوبر يوزر `super_user` لإجراء العمليات الحساسة.
