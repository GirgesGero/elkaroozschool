# قاعدة بيانات MySQL الاحترافية لمدرسة الكاروز — EL KAROOZ SCHOOL
## دليل البنية المعمارية والانتقال الكامل للاستغناء عن Supabase

---

## 1. نظرة عامة (Overview)

تم بناء هذه البنية المعمارية لتوفير قاعدة بيانات **MySQL 8.0+ / MariaDB 10.5+** متكاملة واحترافية تطابق بنسبة 100% خصائص وقدرات **Supabase PostgreSQL**، مما يتيح للمشروع الاستغناء الكامل عن أي خدمات سحابية خارجية والاعتماد الذاتي على خادم Hostinger أو أي بيئة استضافة خاصة.

### المميزات المعمارية الرئيسية:
1. **تغطية شاملة لجميع الكيانات (66 جدولاً):**
   - **64 جدولاً تشغيلياً:** تطابق كافة جداول النظام (المتدربون، الحضور، المناهج، الامتحانات، الماراثون، الحائط، المعرض، المكتبة، الصوتيات، الموسوعة، والإشعارات).
   - **جدولان أصيلان لإدارة الهوية:** (`auth_users` و`auth_refresh_tokens`) للاستغناء الكامل عن Supabase Auth (GoTrue).
2. **محرك تخزين متقدم وضبط الترميز العربي:**
   - المحرك: `InnoDB` لضمان المعاملات الذرية (ACID Compliance) والعزل التام وتكامل المفاتيح الأجنبية.
   - الترميز: `utf8mb4` مع الترتيب `utf8mb4_unicode_ci` لدعم النصوص الدينية المشكولة، أسماء الآباء، واللغة العربية بدقة متناهية.
3. **محاكاة الفهارس الجزئية (Partial Unique Indexes):**
   - استخدام الأعمدة الافتراضية المولدة (`VIRTUAL GENERATED COLUMNS`) مثل `active_term_id` لفرض قيد التفرد حصرياً على السجلات غير المحذوفة (`deleted_at IS NULL`).
4. **حماية أمنية وتريجرات أعمال صارمة (Triggers):**
   - تريجر حظر التعديل أو الحذف لسجلات التدقيق (`audit_logs`) لجعلها غير قابلة للتلاعب (`Strictly Immutable`).
   - تريجر حماية مدير النظام الأخير لمنع حذف أو تخفيض صلاحيات آخر مدير نشط.
   - تريجر قفل جلسات الحضور ليل كل خميس بتوقيت القاهرة (`Africa/Cairo` UTC+2).
   - تريجرات المزامنة التلقائية لعدد التعليقات والإعجابات في المنشورات.

## 3. طبقة الخدمات البرمجية البديلة في PHP Backend

للاستغناء عن Supabase، تم تزويد الخادم الخلفي (`backend-api`) بالمكونات البرمجية التالية:

### 3.1 محرك الاتصال والاستعلام (`App\Database\MySQL`)
- نمط Singleton آمن يغلف اتصال PDO مع ضبط دقيق لـ `utf8mb4` وحظر المعاملات المحاكاة.
- يدعم المعاملات الذرية: `beginTransaction()`, `commit()`, `rollBack()`.
- دوال مساعدة مع معلمات مهيأة (Prepared Statements): `query()`, `fetchOne()`, `fetchAll()`, `insert()`, `update()`, `delete()`.

### 3.2 بديل Supabase Auth (`App\Auth\MySQLAuthService`)
- تشفير كلمات المرور باستخدام خوارزمية `Bcrypt` المقاومة للهجمات.
- حماية ضد هجمات القوة الغاشمة (Brute Force): قفل الحساب تلقائياً لمدة 60 ثانية بعد 5 محاولات خاطئة متتالية.
- توليد توكنات JWT متوافقة 100% مع مواصفات Supabase (`sub`, `aud: 'authenticated'`, `role`, `app_metadata`, `user_metadata`).
- إدارة رموز التحديث (Refresh Tokens) المشفرة بـ SHA-256 مع خاصية التدوير التلقائي (Rotation).

### 3.3 بديل PostgREST التلقائي (`App\Controllers\DataApiController`)
- بوابة استعلام وتحكم في البيانات تدعم العمليات الحسابية والفلترة والترتيب والترقيم.
- **تطبيق سياسات RLS برمجياً (Application-Level RLS):**
  - عزل المتدربين داخل فرقهم الدراسية تلقائياً (`group_id = user.group_id`).
  - قصر قراءة وتعديل السجلات الخاصة بالمتدرب عليه فقط (`trainee_id = user.id`).
  - الفلترة التلقائية للسجلات المحذوفة ناعماً (`deleted_at IS NULL`).
  - السماح بالإدارة الكاملة لمدراء النظام.

## 4. خطوات التثبيت والنقل على Hostinger (Deployment Guide)

### الخطوة الأولى: إنشاء قاعدة البيانات
1. من لوحة تحكم الاستضافة (hPanel / cPanel)، انتقل إلى **Databases** -> **MySQL Databases**.
2. أنشئ قاعدة بيانات جديدة باسم: `elkarooz_school`.
3. أنشئ مستخدم قاعدة بيانات مع كلمة مرور قوية، وامنحه كامل الصلاحيات (`ALL PRIVILEGES`).

### الخطوة الثانية: استيراد المخطط
1. افتح **phpMyAdmin**.
2. اختر قاعدة البيانات `elkarooz_school`.
3. انتقل إلى تبويب **Import** واختر الملف:
   `database-mysql/schema/COMPLETE_MYSQL_SCHEMA.sql`
4. اضغط **Go** لإتمام بناء الـ 66 جدولاً والتريجرات والبيانات التأسيسية.

### الخطوة الثالثة: ضبط متغيرات البيئة في PHP
أضف المتغيرات التالية إلى ملف `.env` الموجود خارج `public_html/` على الخادم:
```env
DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=elkarooz_school
DB_USERNAME=your_mysql_user
DB_PASSWORD=your_mysql_password
DB_CHARSET=utf8mb4
DB_COLLATION=utf8mb4_unicode_ci

JWT_SECRET=your_32_character_minimum_random_secret_here
```

### الخطوة الرابعة: مزامنة ونقل البيانات الحالية من Supabase (ETL Data Sync)
لتفريغ ونقل كافة السجلات الحية من Supabase إلى MySQL:
```bash
php scripts/sync_supabase_to_mysql.php
```
يقوم هذا السكربت بسحب بيانات الـ 64 جدولاً بتسلسل يعتمد على علاقات المفاتيح الأجنبية وتوليد ملف `database-mysql/supabase_live_data_dump.sql` الجاهز للاستيراد المباشر.
