# 🌟 العرض التقديمي التفاعلي لمدرسة الكاروز للكتاب المقدس

مجلد متكامل ومستقل بذاته يحتوي على جميع ملفات وأصول العرض التقديمي الرقمي التفاعلي.

## 🚀 طريقة التشغيل:
- قم بفتح ملف `index.html` أو `presentation.html` مباشرة في أي متصفح (Chrome, Edge, Firefox, Safari).
- أو انقر مرتين على ملف `RUN_PRESENTATION.bat`.

## 🎮 طرق التحكم والتنقل:
- **نقر الماوس:** انقر في أي مكان على الشاشة للتنقل التلقائي مع تأثير سينمائي وموجة ذهبية.
- **لوحة المفاتيح:**
  - `←` أو المسافة `Space` أو `PageDown`: الشريحة التالية.
  - `→` أو `PageUp`: الشريحة السابقة.
  - `F`: وضع ملء الشاشة (Full Screen).
  - `Home`: العودة لأول شريحة.
  - `End`: الانتقال لآخر شريحة.
- **شاشات اللمس والتابلت والهواتف:** سحب لليمين واليسار (Swipe).
- **شريط التحكم السفلي:** أزرار السابق والتالي والترقيم والنقاط المباشرة.

## 🖨️ التصدير إلى PDF:
- اضغط `Ctrl + P` في المتصفح.
- اختر الطابعة: **Save as PDF**.
- تأكد من تفعيل خيار: **Background graphics** لحفظ جميع الألوان والخلفيات بدقة 16:9.

## 📁 محتويات المجلد:
- `index.html` / `presentation.html`: كود العرض التقديمي بالـ HTML5 + CSS3 + GSAP 3.
- `assets/`: مجلد الصور، اللقطات الحية، الموك آب للشاشات، الأيقونات، ومكتبة `gsap.min.js`.
- `RUN_PRESENTATION.bat`: مشغل تشغيل سريع بنقرة واحدة.
